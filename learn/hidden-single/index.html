How to spot a Hidden Single

Learn Hidden Singles: a number can fit in only one cell of a Sudoku row, column, or box, even when that cell has multiple candidates.

When to look for it

  1. Choose a number missing from a particular row, column, or box.
  2. Check every empty cell in that unit for the candidate.
  3. If just one cell can contain the number, that is a Hidden Single.

A simple example

In one row, the digit 8 is missing. Several cells have multiple candidates, but only column 6 can legally contain 8. Place 8 in that cell.

Why it works: Each number must appear exactly once per row, column, and box. A unique possible location in a unit forces that placement.

Common mistake

Do not require the selected cell to have only one candidate. That would be a Naked Single instead.
