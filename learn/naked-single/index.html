How to spot a Naked Single

Learn how to spot a Naked Single in Sudoku: one cell has only one possible number.

When to look for it

  1. Review an empty cell's row, column and box.
  2. Eliminate every digit already used by those peers.
  3. If exactly one candidate remains, place it with certainty.

A simple example

Suppose a cell in a 9×9 Sudoku has candidates {7} after checking its row, column and box. The number 7 must be placed there.

Why it works: Every cell must contain exactly one of the digits 1–9. When eight alternatives are ruled out by existing placements, the remaining candidate is forced.

Common mistake

Don't guess because a number seems likely. Verify that every other candidate is genuinely ruled out.
