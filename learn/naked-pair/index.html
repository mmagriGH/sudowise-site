How to spot a Naked Pair

Learn the Naked Pair technique: two cells in one unit contain exactly the same two candidates.

When to look for it

  1. Inspect one row, column, or box.
  2. Find two empty cells whose candidate sets are exactly the same two digits.
  3. Remove those two digits from every other cell in that unit.

A simple example

Two empty cells in a row each have only {2,9}. Together they must contain 2 and 9, so no other cell in that row can contain either number.

Why it works: The two digits must occupy the two pair cells in some order. Those digits are therefore excluded from all other cells of the same unit.

Common mistake

Two cells merely sharing the same two candidates are not a pair if either cell also has other candidates.
